## Current nonsense

### `mouse3000.py`

A tiny terminal game on a 5×5 board. You are a mouse. Collect both cheeses, avoid the hunter, and reach the door. The hunter moves after each valid move because apparently life was too easy.

```bash
python3 mouse3000.py
```

Type `w`, `a`, `s`, or `d`, then press Enter to move. Use `Ctrl+C` to quit.

Python 3, no third-party dependencies. Bugs are part of the learning process and occasionally part of the game mechanics.
